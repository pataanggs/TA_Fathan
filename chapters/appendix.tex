\section{Dataset}
Dataset yang digunakan dalam penelitian ini adalah dataset publik LibriVox Indonesia versi 1.0 yang disediakan oleh \textit{Indonesian-nlp} melalui platform Hugging Face (\url{https://huggingface.co/datasets/indonesian-nlp/librivox-indonesia}).

Dataset ini terdiri dari audio berformat MP3 dan file teks transkrip terkait yang dihasilkan dari buku-buku audio domain publik LibriVox. Pengumpulan data dalam repositori tersebut difokuskan secara khusus pada bahasa-bahasa di Indonesia. Durasi asli buku audio LibriVox bervariasi dari beberapa menit hingga beberapa jam. Namun, pada dataset ini, setiap file audio telah disegmentasi sehingga memiliki durasi mulai dari beberapa detik hingga maksimal 20 detik.

Konversi buku audio tersebut menjadi dataset ucapan dilakukan menggunakan perangkat lunak penyelarasan paksa (\textit{forced alignment}) yang dikembangkan oleh pihak pengembang. Perangkat lunak ini dirancang untuk mendukung multibahasa, termasuk bahasa-bahasa dengan sumber daya terbatas (\textit{low-resource}), seperti Aceh, Bali, maupun Minangkabau, tanpa memerlukan pekerjaan tambahan untuk melatih model penjajaran. Secara keseluruhan, dataset dari repositori utama saat ini terdiri dari total 8 jam rekaman dalam 7 bahasa dari Indonesia.

Meskipun repositori utama menyediakan berbagai bahasa daerah, penelitian ini secara khusus hanya mengekstraksi dan menggunakan subset penyusun dataset berbahasa Minangkabau. Bahasa daerah lain (seperti Aceh, Bali, Jawa, dll.) yang terdapat di dalam koleksi LibriVox Indonesia tersebut tidak digunakan sama sekali dalam proses pelatihan maupun evaluasi model pada penelitian ini.

\section{Repositori Log Pelatihan (\textit{Weights \& Biases})}
\label{app:wandb}

Seluruh rekam jejak, metrik, dan grafik pelatihan AI dalam penelitian ini didokumentasikan secara transparan menggunakan \textit{Weights \& Biases} (WandB). Platform ini bertindak seperti "buku rapor" interaktif yang mencatat secara \textit{real-time} setiap perkembangan mesin dari awal ia belajar hingga selesai.

Bagi orang awam maupun penguji yang ingin melihat buktinya, platform ini menyajikan:
\begin{itemize}
    \item \textbf{Grafik Penurunan Kesalahan}: Kurva yang memperlihatkan bagaimana tingkat kesalahan AI yang awalnya sangat tinggi perlahan menurun seiring berjalannya proses belajar.
    \item \textbf{Pembandingan Mesin}: Performa sistem ketika menggunakan metode \textit{Freeze Encoder} yang diadu langsung melawan metode \textit{LoRA}.
    \item \textbf{Laporan Durasi Waktu}: Riwayat lengkap tentang berapa lama mesin membutuhkan waktu untuk berlatih di setiap percobaan.
\end{itemize}

Seluruh eksperimen secara independen dapat diakses dan diverifikasi melalui tautan dasbor publik berikut: \\

\section{Snippet Kode Latihan (Training) LoRA dan Freeze Encoder}
\label{app:training_code}

Berikut ini merupakan beberapa potongan kode (\textit{code snippet}) konfigurasi dan implementasi pelatihan pada model Whisper menggunakan metode adaptasi \textit{Low-Rank Adaptation} (LoRA) serta \textit{Freeze Encoder}, ditambah dengan implementasi penanganan \textit{data imbalance} melalui \textit{Weighted Cross-Entropy}.

\subsection{Implementasi Pelatihan dengan LoRA}
Pada pendekatan \textit{Parameter-Efficient Fine-Tuning} (PEFT) dengan menggunakan LoRA, sebagian besar bobot model dibekukan. Berikut konfigurasi dan inisialisasi pembentukan model parametrik menggunakan ukuran matriks ber-\textit{rank} rendah ($r=16$).

\textbf{1. Konfigurasi LoRA (\texttt{code/lora/config.py})}
\begin{lstlisting}[language=Python]
LORA_CONFIG = {
    "r": 16,                         # Increased rank to support target modules
    "lora_alpha": 32,                # Scaling factor (alpha/r)
    "lora_dropout": 0.15,            # Dropout rate on LoRA layers
    "target_modules": [              # Attention + FFN linear layers
        "q_proj", "v_proj", "k_proj", "out_proj", "fc1", "fc2"
    ],
    "bias": "none",
    "task_type": "SEQ_2_SEQ_LM",
    "modules_to_save": [],           
}
\end{lstlisting}

\textbf{2. Modifikasi Model menggunakan PEFT (\texttt{code/lora/trainer.py})}
\begin{lstlisting}[language=Python]
from peft import LoraConfig, get_peft_model

def apply_lora(model):
    """Apply LoRA adapters to the Whisper model."""
    lora_config = LoraConfig(
        r=LORA_CONFIG["r"],
        lora_alpha=LORA_CONFIG["lora_alpha"],
        lora_dropout=LORA_CONFIG["lora_dropout"],
        target_modules=LORA_CONFIG["target_modules"],
        bias=LORA_CONFIG["bias"],
        task_type=None,

Pada metode \textit{Freeze Encoder}, bagian \textit{encoder} sepenuhnya dibekukan dan \textit{decoder} dilatih. Berbeda dari LoRA, bagian ini melatih jutaan parameter \textit{decoder} secara utuh.

\begin{lstlisting}[language=Python]
def freeze_encoder(model):
    """Freeze the encoder weights; only train the decoder."""
    # Matikan gradien pada layer encoder
    model.model.encoder.requires_grad_(False)
    
    # Nyalakan kembali/pastikan gradien bekerja pada layer decoder
    model.model.decoder.requires_grad_(True)
    
    return model
\end{lstlisting}

\subsection{Weighted Cross-Entropy Loss (\texttt{code/weighted\_ce.py})}
Pendekatan kustom untuk menghitung \textit{Cross-Entropy Loss} yang telah diberikan bobot (\textit{weighted}) pada level fonem agar model memberikan penalti yang lebih tinggi ketika salah memprediksi pada karakter/fonem minoritas (*data imbalance*).

\begin{lstlisting}[language=Python]
import torch

class WeightedCEMixin:
    """
    Custom Mixin untuk Seq2SeqTrainer guna menghitung 
    Weighted Cross-Entropy dengan label smoothing.
    """
    def compute_loss(self, model, inputs, num_items_in_batch=None, **kwargs):
        # 1. Pre-compute decoder_input_ids for label smoothing
        if "labels" in inputs and "decoder_input_ids" not in inputs:
            labels = inputs["labels"]
            decoder_input_ids = labels.new_zeros(labels.shape)
            decoder_input_ids[:, 1:] = labels[:, :-1].clone()
            decoder_input_ids[:, 0] = model.config.decoder_start_token_id
            decoder_input_ids = decoder_input_ids.masked_fill(
                decoder_input_ids == -100, model.config.pad_token_id
            )
            inputs["decoder_input_ids"] = decoder_input_ids

        # Gunakan method standard jika tidak ada bobot yang dimuat
        if getattr(self, "token_weights", None) is None:
            return super().compute_loss(model, inputs, **kwargs)

        # 2. Forward pass untuk mendapatkan logits
        labels = inputs.pop("labels")
        outputs = model(**inputs)
        logits = outputs.logits

        # 3. Formulasi kalkulasi Weighted Cross-Entropy Loss
        loss_fct = torch.nn.CrossEntropyLoss(
            weight=self.token_weights.to(logits.device),
            label_smoothing=self.args.label_smoothing_factor
        )
        
        # Hitung loss untuk entire batch / dimension token
        loss = loss_fct(
            logits.view(-1, model.config.vocab_size), 
            labels.view(-1)
        )

        return (loss, outputs) if "return_outputs" in kwargs and kwargs["return_outputs"] else loss
\end{lstlisting}


\subsection{Konversi Audio (\texttt{code/convert\_audio.py})}
Skrip ini digunakan untuk melakukan konversi awal seluruh file audio ke format WAV dengan \textit{sample rate} 16 kHz agar sesuai dengan format masukan standar model Whisper.

\begin{lstlisting}[language=Python]
import librosa
import soundfile as sf
from config import SAMPLE_RATE

def convert_audio_to_wav(input_path: str, output_path: str) -> bool:
    '''Convert audio file to WAV format at 16kHz.'''
    try:
        # Load audio
        audio, sr = librosa.load(input_path, sr=SAMPLE_RATE, mono=True)
        
        # Normalize amplitude
        max_val = max(abs(audio.max()), abs(audio.min()))
        if max_val > 0:
            audio = audio / max_val
        
        # Save as WAV
        sf.write(output_path, audio, SAMPLE_RATE)
        return True
    except Exception as e:
        print(f"Error: {input_path} - {e}")
        return False
\end{lstlisting}

\subsection{Pra-pemrosesan Teks (\texttt{code/text\_preprocessing.py})}
Pemrosesan teks transkripsi berfokus pada tahapan \textit{lowercasing} (huruf kecil semua), penghapusan tanda baca (\textit{punctuation removal}) dengan mempertahankan angka, dan normalisasi spasi kosong.

\begin{lstlisting}[language=Python]
import re
import string

def remove_punctuation(text: str, keep_digits: bool = True) -> str:
    '''Remove punctuation from text while optionally keeping digits.'''
    if keep_digits:
        pattern = f"[{re.escape(string.punctuation)}]"
        text = re.sub(pattern, " ", text)
    else:
        text = text.translate(str.maketrans("", "", string.punctuation))
    return text

def preprocess_text(text: str) -> str:
    '''Full text preprocessing pipeline.'''
    if not isinstance(text, str):
        return ""
    text = text.lower()
    text = remove_punctuation(text, keep_digits=True)
    text = re.sub(r"\s+", " ", text).strip()
    return text
\end{lstlisting}

\subsection{Augmentasi Data (\texttt{code/augmentation.py})}
Teknik augmentasi data yang diterapkan mencakup \textit{Speed Perturbation} (perubahan kecepatan), \textit{Noise Injection} (penambahan \textit{noise}), \textit{Pitch Shift} (pergeseran nada), dan pengapilkasian \textit{SpecAugment} pada \textit{mel-spectrogram}. Pendekatan ini esensial pada pelatihan set data berukuran kecil untuk mencegah pelebihaan kecocokan (\textit{overfitting}).

\begin{lstlisting}[language=Python]
class AudioAugmenter:
    '''Combined audio augmentation pipeline for training.'''
    
    def augment_waveform(self, audio: np.ndarray, sample_rate: int = 16000) -> np.ndarray:
        # 1. Random speed perturbation
        if self.use_speed_perturbation and random.random() < self.prob:
            audio = self.speed_perturb(audio, sample_rate)
            
        # 2. Random pitch shift
        if self.use_pitch_shift and random.random() < self.prob:
            audio = self.pitch_shift(audio, sample_rate)
            
        # 3. Random noise injection
        if self.use_noise_injection and random.random() < self.prob:
            audio = self.noise_inject(audio)
            
        return audio
        
    def augment_spectrogram(self, mel_spectrogram: torch.Tensor) -> torch.Tensor:
        # 4. SpecAugment (Time and Frequency Masking)
        if self.use_specaugment and random.random() < self.prob:
            mel_spectrogram = self.specaugment(mel_spectrogram)
        return mel_spectrogram
\end{lstlisting}

def dataframe_to_hf_dataset(df: pd.DataFrame) -> Dataset:
    '''Convert pandas DataFrame to HuggingFace Dataset.'''
    dataset_df = df[["full_path", "transcript"]].copy()
    dataset_df = dataset_df.rename(columns={

\subsection{Konstruktor Dataset \& Data Collator (\texttt{code/dataset.py})}
Tahapan yang menyatukan logik pemrosesan audio (mendapatkan masukan \textit{input features}/spektrogram) dan pelabelan teks (\textit{input ids}) menjadi format \textit{batch} tensor siap komputasi agar sesuai dengan format masukan model Seq2Seq.

\begin{lstlisting}[language=Python]
def prepare_dataset(batch, processor, augmenter=None, is_training=True):
    audio = load_processed_audio(batch["audio_path"])
    
    if is_training and augmenter is not None:
        audio = augmenter.augment_waveform(audio)
        
    input_features = processor.feature_extractor(
        audio, sampling_rate=SAMPLE_RATE, return_tensors="np"
    ).input_features[0]
    
    if is_training and augmenter is not None:
        input_features_tensor = torch.from_numpy(input_features).unsqueeze(0)
        input_features_tensor = augmenter.augment_spectrogram(input_features_tensor)
        input_features = input_features_tensor.squeeze(0).numpy()
        
    batch["input_features"] = input_features
    text = preprocess_text(batch["text"])
    batch["labels"] = processor.tokenizer(text).input_ids
    return batch
\end{lstlisting}

Modul sistem penebaran \textit{log} kustom berbasis evaluasi metrik ASR generik di antaranya \textit{Word Error Rate} (WER), \textit{Character Error Rate} (CER), durasi eksekusi, serta rekaman loss model, yang dapat disimpan secara berkesinambungan secara lokal pada format CSV/JSON maupun diteruskan ke portal evaluasi eksternal \textit{Weights \& Biases} (WandB).

class ComprehensiveMetricsCallback(TrainerCallback):
    '''Custom callback that logs all metrics during training.'''
    
    def on_evaluate(self, args, state, control, metrics=None, **kwargs):
        '''Log evaluation metrics globally and per-epoch.'''
        if metrics is not None:

                eval_loss=loss,
                wer=wer,
                cer=cer
            )
