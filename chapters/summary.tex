	\large \bfseries \MakeUppercase{Ringkasan}\\

	\bigskip
	
	\normalsize \normalfont \justifying
	\normalsize \normalfont \justifying
	Teknologi \textit{Automatic Speech Recognition} (ASR) masih kurang mendukung bahasa bersumber daya rendah (\textit{low-resource}) seperti Minangkabau akibat keterbatasan dataset dan tingginya variasi dialek. Oleh karena itu, penelitian ini bertujuan mengadaptasi model bahasa universal secara efisien ke bahasa daerah Minangkabau. Penelitian dilakukan melalui proses \textit{fine-tuning} model OpenAI Whisper Base menggunakan arsitektur \textit{Parameter-Efficient Fine-Tuning} via \textit{Low-Rank Adaptation} (LoRA) untuk meminimalisasi beban komputasi. Optimasi \textit{Weighted Cross-Entropy Loss} turut diintegrasikan guna mengatasi ketimpangan kemunculan fonem pada set pelatihan.

	Evaluasi menggunakan \textit{Word Error Rate} (WER) dan \textit{Character Error Rate} (CER) membuktikan terwujudnya peningkatan akurasi yang signifikan dibandingkan mode \textit{zero-shot} asalnya. Implementasi ganda antara metrik bobot kerugian dan LoRA sukses mereduksi kesalahan fonetik, walaupun sistem masih rentan terhadap diksi yang jarang terjadi. Kesimpulannya, metode eksperimental yang diuji ini merupakan kerangka yang efektif dan hemat biaya sumber daya untuk merancang ASR bahasa lokal. Disarankan untuk meluaskan representasi data wicara Minangkabau pada korpus masif masa depan untuk mempertinggi utilitas dunia nyata.
